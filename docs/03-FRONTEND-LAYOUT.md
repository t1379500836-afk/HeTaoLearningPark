## 响应式设计

### 断点规范

| 断点 | 屏幕宽度 | 设备类型 | 说明 |
|------|----------|----------|------|
| `--breakpoint-xs` | `480px` | 手机小屏 | 最小设备 |
| `--breakpoint-sm` | `768px` | 手机标准 | 主流手机 |
| `--breakpoint-md` | `1024px` | 平板 | iPad等 |
| `--breakpoint-lg` | `1200px` | 桌面 | 标准桌面 |

### 媒体查询使用

```css
/* 手机优先 */
.component {
  font-size: 14px;
}

/* 平板及以上 */
@media (min-width: 768px) {
  .component {
    font-size: 16px;
  }
}

/* 桌面 */
@media (min-width: 1024px) {
  .component {
    font-size: 18px;
  }
}
```

### 设备适配表

| 设备 | 屏幕宽度 | 布局要求 |
|------|----------|----------|
| 手机 | < 768px | 单列布局，大字体，简化交互 |
| 平板 | 768px - 1023px | 优化触控，适当放大间距 |
| 桌面 | ≥ 1024px | 多列布局，充分利用空间 |

### 触控优化

| 要求 | 值 | 说明 |
|------|-----|------|
| 按钮最小尺寸 | 44×44px | 适合手指触控 |
| 避免悬停依赖 | - | 确保所有功能可通过触控完成 |
| 手势支持 | - | 支持滑动、点击等基础手势 |

#### 响应式导航菜单（移动端）

| 断点 | 菜单宽度 | 说明 |
|------|---------|------|

### 悬浮返回按钮

**适用页面**: StageView、UnitView、LessonView

课程详情页的左下角设有橙色悬浮返回按钮，方便用户返回上一级页面。

```
┌─────────────────────────────────────┐
│                                     │
│         页面内容区域                 │
│                                     │
│                                     │
│                              [←]    │ ← 悬浮返回按钮
└─────────────────────────────────────┘
```

| 属性 | 桌面端 | 平板端 | 手机端 |
|------|--------|--------|--------|
| 尺寸 | 56×56px | 54×54px | 52×52px |
| 位置 | bottom: 30px, left: 30px | bottom: 25px, left: 25px | bottom: 20px, left: 20px |
| 背景色 | `#ff9f43` (橙色) | 同左 | 同左 |
| 文字颜色 | `#fff` (白色) | 同左 | 同左 |

**实现代码** (Vue 3 Composition API):
```javascript
import { useRouter } from 'vue-router'

const router = useRouter()
const goBack = () => {
  router.back()
}
```

## 页面跳转逻辑

### 导航流程

```
首页 (/)
  ├─→ 课程体系 (/levels)
  │     └─→ 阶段详情 (/levels/PY2)
  │           └─→ 单元详情 (/levels/PY2/L7)
  │                 └─→ 课时详情 (/lesson/PY2/L7/L7-1)
  ├─→ 打字练习 (/typing)
  └─→ Python编辑器 (/python)
```

### 路由跳转方式

| 方式 | 说明 | 示例 |
|------|------|------|
| `router-link` | 声明式导航 | `<router-link to="/levels">` |
| `router.push()` | 编程式导航 | `router.push('/levels/PY2')` |
| 命名路由 | 通过name跳转 | `router.push({ name: 'lesson', params: {...} })` |

---

## 设计原则

1. **移动优先**: 从小屏幕开始设计，渐进增强
2. **一致性**: 保持不同设备间的视觉风格和交互一致性
3. **可访问性**: 确保所有用户都能使用
4. **性能**: 优化加载速度和渲染性能
